### 1. **Material** — `tools/src/verify/menubar.mjs:175`: the new guard reads a *colour*, never a painted border, so the state signal can disappear entirely and the check stays green at 16.04:1

### 2. **Minor** — `apps/studio/src/app/studio-toolbar.tsx:42`: the region toggles carry no project focus ring, so the answer to "does a pressed chip resemble a focused one" currently depends on a Chrome default

Pre-existing, not introduced by c90ded1, but it is what the brief's focus question actually turns on. `LANDMARK_FOCUS` (`apps/studio/src/app/studio-regions.ts:22-23`) is applied to the wrapping `<section>` at `studio-toolbar.tsx:23`, never to `RegionButton`. **Fix I would make:** append `LANDMARK_FOCUS` to the `RegionButton` className. It costs one identifier and it removes the dependence on a browser default for a control whose state indicator this wave just spent four passes measuring.
